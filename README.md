# Sparrow Estimating

Estimating and proposal work for Sparrow Woodworks (general contracting + millwork, Indianola, WA). This work was moved here from the "Sparrow Estimating" project in Claude chat.

## What's here

```
skills/sparrow-estimate-proposal/SKILL.md   House process: plans -> CSI estimate -> client proposal
cost-database/                              Snapshot of the Sparrow Cost Database Sheet (projects, escalation)
estimates/                                  Estimate write-ups and comparisons
proposals/<project>/index.html              Client proposal pages (open in a browser)
```
